# QQ群智能守护者 (GroupGuardian)

### 多 Bot 配置（本地版）

在插件管理页面顶部选择 QQ 账号。设置、群名单、单群规则、操作记录和定时任务按账号保存。要让同群的 A 负责群管，可将群号加入 A 的白名单，在 B 的「设置」中关闭「当前 Bot 群管开关」并保存。白名单留空表示允许所有未列入黑名单的群。

每个账号的数据位于插件数据目录下的 `bots/<QQ号>/`。旧版的基础设置、名单和单群规则用于初始化账号。首次从旧数据库升级时，插件在 `before-bot-profiles/` 保存原数据库快照和基础设置。旧审核日志、申诉和待解禁任务保留在旧库，因缺少执行账号，不自动分配或重放。各账号后续的更改通过插件专页保存。

面向 AstrBot 的 QQ 群综合管理插件，集 **AI 内容审核**、**防刷屏与申诉解禁**、**入群审核与名片监控**、**35 项群管指令 / 22 项 AI 工具** 以及 **内置 WebUI 面板** 于一体，支持单实例多 QQ 账号独立群管。

> 本分支基于 **v2.8.11**，需要 **AstrBot 4.24.2 或更高版本**，通过 `aiocqhttp` 接入 OneBot 协议端（如 NapCat）。

## 核心功能

- **智能内容审核**：结合内置词库、规则和 LLM 判断群消息。可按需开启合并转发、图片 OCR、表情、二维码、编码文本与伪装链接审核。管理员可以标记误判，再审批 AI 复盘生成的候选规则。
- **防刷屏与申诉解禁**：按 1 秒 / 60 秒 / 3600 秒滑动窗口监测消息频率，支持夜间独立限速、重复消息与长文本刷屏检测、QQ 收藏自动撤回；触发处罚后可选开启私聊申诉复核与到期自动解禁。
- **入群审核与名片监控**：按群配置加群通过词、拒绝词、词库过滤与 LLM 语义审核（可选按需联网核查）；支持名片变更记录、名片保护自动还原、违规名片审核与管理员任免通知（总开关默认关闭）。
- **自适应词库学习**：可选从群聊上下文自动挖掘本群特有引流黑话，按群独立沉淀为候选词，默认经人工审批生效（总开关默认关闭）。
- **多 Bot 独立群管与多群覆盖**：同一 AstrBot 实例接入多个 QQ 账号时，各账号独立维护开关、群黑白名单、单群策略、日志与定时任务；单群可按需覆盖全局默认配置。
- **内置 WebUI 管理面板**：直接挂载在 AstrBot Dashboard 中，复用框架登录鉴权，无需额外开放端口。

## 快速开始

### 1. 安装插件

- **试用本分支的多 Bot 功能**：下载[功能分支 ZIP](https://github.com/timeance/astrbot_plugin_group_guardian/archive/refs/heads/feat/per-bot-group-management.zip)，在 AstrBot WebUI → 插件 → 安装插件 中上传，再重载插件。
- **安装市场版本**：在 AstrBot WebUI → 插件 → 插件市场 中搜索 `QQ群智能守护者`。市场版的功能以其发布版本为准。

### 2. 首次配置

1. 在插件管理页顶部选择要配置的 QQ 账号，在「设置」中阅读并同意使用须知（`disclaimer_agreed`）。
2. 在该账号的插件管理员名单（`admin_list`）中添加负责人的 QQ 号并保存。其他账号需要分别设置。
3. 确保机器人在目标群拥有**管理员或群主**权限（默认开启 `moderation_require_bot_admin`，非管理群会自动跳过审核）。
4. 确认 AstrBot 已配置可用的 LLM Provider；如需识图审核，再单独开启 `ocr_enabled` 并指定支持视觉能力的模型。

### 3. 打开管理面板

在 AstrBot Dashboard 中进入本插件管理页即可完成规则维护、违规复核、远程群管和参数调整。如实例连接了多个 QQ 账号，先在页面顶部「**群管 Bot**」下拉框中选择要管理的账号。

## 多 Bot 独立配置与数据迁移

当同一个 AstrBot 实例连接多个 QQ 账号时：

- **按账号独立管理**：在插件管理页顶部选择 QQ 账号后，所有开关、群名单、单群规则、审核记录和定时任务均仅作用于当前账号。
- **A 管群 1，B 管群 2**：两个账号都开启群管。先选 A，白名单只填群 1 并保存；再选 B，白名单只填群 2 并保存。即使两个账号都加入了这两个群，也只有对应账号处理各自群里的消息和指令。
- **只让 A 负责群管**：在 B 的「设置」里关闭「当前 Bot 群管开关」并保存。如果 B 还需要管理其他群，可以只把群 1 加入 B 的黑名单。**清空 B 的白名单会放行所有未拉黑的群**。黑名单优先于白名单。
- **远程操作**：对已经建立配置的账号，离线时仍可查看和编辑配置。所选账号离线或关闭群管时，面板的远程执行接口会拒绝禁言、踢人等操作。
- **目录与升级迁移**：
  - 每个账号的数据独立存放在插件数据目录下的 `bots/<QQ号>/`（含 `config.json` 与 `group_guardian.db`）。
  - 检测到旧数据库时，插件在 `before-bot-profiles/` 保存原数据库快照和基础设置。新账号继承基础词库、审核与入群规则、名单、权限及单群配置。
  - 旧审核日志、申诉记录与待解禁任务因缺少执行账号归属，保留在旧库中，不会自动分配或重放。

## 常用配置项

新账号从 AstrBot 插件配置读取初始值。已有账号请在插件专页顶部选中该账号，再通过「设置」「权限管理」或「多群配置」修改并保存。

### 基础与权限

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 当前 Bot 群管开关；关闭后该账号跳过群管消息、指令与定时任务 |
| `disclaimer_agreed` | `false` | 使用须知确认开关，首次使用需开启 |
| `admin_list` | `[]` | 插件管理员 QQ 号列表 |
| `group_white_list` / `group_black_list` | `[]` | 群白名单（留空允许全部未拉黑群）/ 群黑名单 |
| `user_white_list` / `user_black_list` | `[]` | 用户白名单（豁免审核与防刷屏）/ 用户黑名单（自动拒绝加群并处置） |
| `moderation_require_bot_admin` | `true` | 机器人在该群不是管理员/群主时自动跳过审核与防刷屏 |
| `moderation_admin_exempt` | `false` | 开启后群主、群管与插件管理员豁免内容审核（防刷屏始终豁免） |
| `official_bot_exempt_enabled` | `false` | 豁免 QQ 开放平台官方机器人消息（可按群覆盖） |

### 内容审核与 OCR

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `auto_moderate_enabled` | `true` | 智能审核总开关 |

### 防刷屏、入群、名片与词库学习

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `anti_flood_enabled` | `true` | 防刷屏总开关 |

## 常见问题

**Q：QQ 官方机器人（`qq_official`）能用吗？**

本分支按 `aiocqhttp` 上报的 QQ 账号处理消息和指令，包括违禁词查询。请通过该适配器接入 OneBot 协议端。

**Q：为什么安装后审核和指令完全不生效？**

选中接收消息的账号，检查是否已同意使用须知、已开启群管，且群号符合该账号的黑白名单规则。执行撤回或禁言时，还需要确认该 Bot 在目标群拥有相应权限。

**Q：同一实例登了两个 QQ，同群里两个号都在响应怎么办？**

在插件 WebUI 顶部「群管 Bot」下拉框中分别切换两个账号：只让负责群管的账号在白名单中保留该群，另一个账号关闭「当前 Bot 群管开关」或将该群加入黑名单并保存即可。

**Q：管理指令提示无权限？**

先确认面板选中的 Bot、目标群和发送者 QQ 号，再检查该账号的插件管理员名单与本群授权。设置群管理员等操作还要求 Bot 本身在 QQ 群中有相应权限。

**Q：自动审核出现误判怎么处理？**

在 WebUI「违规记录」中将该条日志标记为误判，可手动或定期触发 AI 误判复盘生成修正规则，人工确认后生效；也可直接在「规则中心」禁用或调整对应关键词/规则。

**Q：名片监控开启后没有记录或不会还原？**

先改一次群名片并查看 AstrBot 日志：若未出现 `[GroupMgr] 收到名片变更事件`，说明协议端未上报非标准 `group_card` 事件，插件会按 `card_sync_interval`（默认 120 秒）周期同步兜底。若只拦链接不拦引流昵称，请改开 `card_audit_enabled` 全量审核。另外协议事件不含操作者 ID，无法区分是本人修改还是管理员修改。

**Q：图片或二维码没有触发审核？**

识别图片文字可开启 `ocr_enabled` 并配置视觉模型。只需读取图片中的二维码时，可开启 `qrcode_decode_enabled`，二维码解码本身无需视觉模型。
